Design System Summary

Complete specification untuk brutalist redesign

Design Direction

Asymmetric Blocks — Bauhaus meets Brutalism

High-contrast black/white design dengan broken grid layouts, inverted sections, dan geometric shapes. No rounded corners, no shadows, no smooth transitions.

PHILOSOPHY
Function over form, honest materials, raw aesthetic
PERSONALITY
Bold, distinctive, anti-polish, memorable
TARGET
Developers, power users, self-hosters

Layout & Grid

RESPONSIVE BREAKPOINTS
  • < 768px — Mobile (single column, stacked)
  • 768px - 1023px — Tablet (hybrid layout)
  • 1024px+ — Desktop (full asymmetric grid)
GRID SYSTEM
  • Asymmetric columns (2fr 1fr, 200px 1fr, etc.)
  • Grid gaps: 2px (maintains visible borders)
  • Black dividers between sections
  • Inverted sections for hierarchy

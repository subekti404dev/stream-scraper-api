Responsive Principles

DESKTOP
  • Asymmetric 2-column grids
  • Large inverted sections
  • Horizontal navigation
  • Side-by-side forms
TABLET
  • Collapse to single column
  • Action button inline with form
  • Maintain bold contrasts
  • Slightly tighter spacing
MOBILE
  • Stack everything vertically
  • Tab-style navigation
  • Full-width touch targets
  • Compact typography

Color Palette:

#000 — Primary (text, borders, inverted sections)
#fff — Background (main sections, inverted text)
#e8e8e8 — Secondary (inactive states, background variants)

Breakpoints:

  • < 768px — Mobile (single column, stacked)
  • 768px - 1023px — Tablet (hybrid layout)
  • 1024px+ — Desktop (full asymmetric grid)

Grid gaps tetap 2px di semua breakpoints untuk maintain brutalist aesthetic — no soft spacing.
